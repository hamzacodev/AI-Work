# AI-Work

My hands-on AI engineering projects, built while learning LLM engineering.

| Project | What it is |
|---|---|
| [legal-qa-finetune](legal-qa-finetune) | In progress. Fine-tune Llama 3.2 3B on UK legal Q&A, add RAG, and compare 5 approaches with real evaluation numbers. All free tools. |
| [DealDesk](DealDesk) | An AI agent that negotiates with vendors for the buyer, with hard limits enforced by plain code and a test suite. Has a live demo. |
| [rag-lab](rag-lab) | A local RAG system (ChromaDB and Ollama, no frameworks) with a real evaluation harness. |
| [rag-bot](rag-bot) | A small RAG bot: ingest documents into Chroma, then ask questions answered with Groq. |
| [confidence-bot](confidence-bot) | A bot that answers from documents and reports how confident it is in the answer. |
| [research-agent](research-agent) | A tool-using agent with a calculator, unit converter and web search. |
| [Learning_Begin](Learning_Begin) | First steps: a simple chat script using the Groq API. |

## Stack

Python, TypeScript, Groq, ChromaDB, sentence-transformers, Ollama, Hugging Face.
